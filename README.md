# O-Reciclador



É um jogo de gênero educativo em que você tem como ação principal o de reciclar. 

Seu objetivo é fazer a reciclagem dos lixos que aparecerem, enquanto haverão obstáculos que tentaram impedir você de conseguir fazer a reciclagem. 



O intuito do jogo é de que você aprenda a reciclar de forma divertida e didática, pois é claro é um jogo, além disso o jogo em si é em formato 2D.
